# Application de Gestion Agricole

Une application web React pour la gestion des campagnes, des parcelles, des cultures et du suivi financier d'une exploitation agricole.

## Fonctionnalités
- **Gestion des Campagnes** : Planification et suivi des différentes saisons agricoles.
- **Gestion des Parcelles** : Suivi des surfaces cultivées et des statuts des terres.
- **Transactions & Finances** : Suivi des revenus et des dépenses par campagne ou parcelle.
- **Rapports** : Bilan financier global et par campagne.

## Technologies utilisées
- **Frontend** : React, React Router
- **Backend / API** : Node.js (Express, MongoDB)
- **Styles** : CSS personnalisé
